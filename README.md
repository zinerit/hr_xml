HR XML Export (PHP + MySQL)

 Описание
Този проект съдържа PHP скрипт, който се свързва с MySQL база данни (HR схема), извлича данни от таблицата **`departments`** и генерира:  

- XML файл (`hr_export.xml`)  
- DTD файл (`hr_export.dtd`)  

XML документът е валидиран спрямо генерирания DTD и включва секция `<control>` с резюме на данните.

Файлове
- `export_hr.php` – PHP скрипт за връзка с базата и генериране на XML/DTD  
- `hr_export.xml` – Генериран XML документ  
- `hr_export.dtd` – DTD дефиниция за валидиране на XML  

 База данни
- Име на база данни: `hr`  
- Таблица: `departments`  
- Експортирани редове: първите 10 реда, сортирани по първичен ключ (`DEPARTMENT_ID`)  

 Контролна секция
XML документът включва елемент `<control>` със следната информация:  
- `rowCount` – брой редове  
- `columnCount` – брой колони  
- `minId` – минимална стойност на ключа  
- `maxId` – максимална стойност на ключа  
- `checksum` – контролна сума (сума на числовите ключове + дължината на текстовите полета)  

 Технологии
- PHP 8  
- MySQL / MariaDB  
- PDO  
- DOMDocument
